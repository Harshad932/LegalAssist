# ⚖️ Legal Assist

**Legal Assist** is a full-stack legal web application designed to simplify the legal process for clients and lawyers alike. It enables secure **case tracking**, **lawyer discovery**, **messaging**, and an integrated **AI assistant** to help users understand legal terminology and steps. Admins can manage case priorities and users can follow their case progress using unique token numbers.

🌐 [Live Project https://legalassist-frontend.onrender.com] (https://github.com/Harshad932/LegalAssist)

---

## 🚀 Features

### ✅ 1. Case Tracking using Token Number
- Users can check the status of their cases by entering a **case token**.
- Each token is unique and tied to the specific user and case.

### 🧠 2. AI Legal Assistant
- Get help with basic legal queries.
- Uses OpenAI's API (be mindful of limited key usage).
- Can answer any legal queries 

### 👨‍⚖️ 3. Find a Lawyer
- Browse through registered lawyers.
- View their specialization, experience, and fees.
- Send requests to take up a case.

### ⚙️ 4. Admin Panel
- Admins can view all cases and set **priority levels** (High, Medium, Low).
- Manage  case data.

### 📬 5. Messaging System
- Built-in chat system between **User ↔ Lawyer**.
- Track case discussions securely.

### 👥 6. User and Lawyer Accounts
- Users can sign up, track them, and message lawyers.
- Lawyers can view requested cases and chat with clients.
